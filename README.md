# Used Car Marketplace - Frontend MVP

This project is a React frontend MVP for a used car platform.

It includes:

- Search and filter inventory by keyword, city, brand, price, and year
- Sort by price, year, and mileage
- Listing cards with key vehicle details
- Seller contact toggle on each vehicle card
- "Post Your Car" form to add a new listing on the page instantly
- Responsive layout for desktop and mobile

## Quick Start

1. Install dependencies

	npm install

2. Start local development server

	npm start

3. Open browser

	http://localhost:3000

## Scripts

- npm start: Run local development server
- npm test: Run tests
- npm run build: Create production build
